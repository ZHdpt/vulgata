# Backup B 录屏操作脚本

## 录制前准备（不要录入正式镜头）

- [ ] 启动 Backup B，确认登录页、管理后台和对话页都能正常打开。
- [ ] 准备好管理员登录账号；不要让密码管理器、密钥或终端出现在画面中。
- [ ] 将浏览器缩放设为 `100%`，关闭书签栏、下载栏和无关标签页。
- [ ] 清空通知，隐藏鼠标高亮以外的桌面信息。
- [ ] 预热以下问题，确认提供方当前可用：
  - 业务模式：`移动端渠道会话更新包含哪些主要步骤？`
  - 技术模式：`UpdateChannelSessionOp 如何通过跨仓库调用 UpdateSessionOp 更新渠道会话？`
- [ ] 预热成功后，刷新并回到登录页，再开始正式录制。

> 录屏固定知识范围：System 使用“手机银行登录与注册知识库”，Repository 使用 `mbs_account` 和 `mbs_channel`。

## 正式录制

### 1. 登录

- [ ] 从 Vulgata 登录页开始，停留约 2 秒，展示品牌和登录界面。
- [ ] 输入管理员账号和密码，点击“登录”。
- [ ] 登录后停留约 2 秒，让对话首页完整呈现。

旁白建议：Vulgata 将跨 Repository 的代码与业务知识汇总到同一个可追溯知识库中。

### 2. 进入管理后台

- [ ] 点击顶部导航“管理后台”。
- [ ] 等待表格稳定后，缓慢移动鼠标经过 Repository 列表。
- [ ] 指出 `mbs_account` 行的“扫描状态”“最近扫描时间”和“文档数量”。
- [ ] 确认画面中能看到 `mbs_channel`，但本次只操作 `mbs_account`。

旁白建议：管理后台展示每个 Repository 的扫描状态、最近扫描时间和已生成的文档数量。

### 3. 触发 `mbs_account` 扫描

- [ ] 在 `mbs_account` 行点击“开始扫描”。
- [ ] 停留约 2 秒，清楚展示状态变为“扫描中”，按钮也显示“扫描中”。
- [ ] 点击同一行最右侧的“查看”。

旁白建议：现在启动 `mbs_account` 的扫描，并进入扫描进度视图。

### 4. 展示扫描进度动画

- [ ] 等待全屏扫描动画完全载入。
- [ ] 展示仓库结构、代码文件和知识文档/关系图的动态处理过程。
- [ ] 二选一：
  - 完整镜头：持续录制约 `1 分 55 秒`，直到出现“扫描完成”。
  - 精简镜头：连续录制 `10–15 秒`，后期跳切到返回动作。
- [ ] 点击左上角“返回管理后台”。不要刷新页面或重启应用，否则会丢失本次会话中的演示状态。

> 动画的三个阶段分别约为 15 秒、60 秒和 40 秒。进入动画页时，演示状态已经在当前 Blazor 会话中记为完成，因此精简镜头也可安全返回。

### 5. 确认扫描完成

- [ ] 回到管理后台后，找到 `mbs_account`。
- [ ] 停留约 3 秒，展示状态已经变为“扫描完成”。
- [ ] 展示更新后的“最近扫描时间”和增加后的“文档数量”。
- [ ] 如需强调对比，将鼠标依次移到状态、时间和文档数量上，但不要再次点击“开始扫描”。

旁白建议：扫描完成后，Repository 状态、完成时间和知识文档数量都会更新。

### 6. 返回对话并选择知识范围

- [ ] 点击顶部导航“对话”。
- [ ] 点击输入框旁的 Repository 选择器。
- [ ] 在“手机银行登录与注册知识库”下选择 `mbs_account` 和 `mbs_channel`。
- [ ] 确认输入框旁出现两个 Repository 标签。

旁白建议：对话可以限定到一个 System 下的两个 Repository，从而回答跨 Repository 的业务与技术问题。

### 7. 业务模式提问

- [ ] 选择“业务模式”。
- [ ] 输入：`登录认证错误次数超过上限会怎样？`
- [ ] 点击“发送”，等待渐进式文字动画完整结束。
- [ ] 回答完成后停留约 3 秒。
- [ ] 展开一个“查看来源”，展示回答可以追溯到 Repository、文件和代码行。
- [ ] 输入：`登录密码校验失败后会怎样？`
- [ ] 点击“发送”，等待渐进式文字动画完整结束。
- [ ] 回答完成后停留约 3 秒。
- [ ] 输入：`客户信息和会话令牌在跨仓库更新过程中如何被保存？`
- [ ] 点击“发送”，等待渐进式文动画完整结束。
- [ ] 回答完成后停留约 3 秒。

预期内容包括：消费方设置调用参数；提供方校验并保存客户信息；构造 Redis key、保存会话和 token；提交会话。

### 8. 技术模式提问

- [ ] 切换到“技术模式”；确认上一轮对话仍保留在时间线中。
- [ ] 展示 `mbs_account` 与 `mbs_channel` 两个 Repository 的文件路径和行号引用。
- [ ] 输入：`UpdateChannelSessionOp 调用 UpdateSessionOp 时设置了哪些 SOFA 参数？`
- [ ] 点击“发送”，等待回答和引用完整显示。
- [ ] 点击新对话按钮，输入：`UpdateSessionOp 如何构造 Redis key、写入 token 并提交会话？`
预期引用：

- `mbs_account` / `UpdateChannelSessionOp.java` 第 32–52 行；
- `mbs_channel` / `UpdateSessionOp.java` 第 25–62 行。

### 9. 展示知识边界

- [ ] 输入：`明天天气怎么样？`
- [ ] 点击“发送”。
- [ ] 等待约 1–2 秒，展示：`当前知识库中没有足够信息回答该问题。`
- [ ] 停留约 3 秒。

旁白建议：当问题超出当前知识库证据范围时，系统会明确拒答，而不是生成无法追溯的内容。

### 10. 退出登录

- [ ] 点击右上角用户头像/用户名，打开账户菜单。
- [ ] 点击“退出登录”。
- [ ] 等待返回登录页，停留约 3 秒后结束录制。

## 异常处理

- 如果业务问题出现“当前知识证据不可用或已更新，请稍后重试”，不要在正式镜头里重复发送；停止该段，刷新后先在镜头外预热，再重录对话段。
- 如果技术问题超时，等待界面恢复后停止该段；不要展示终端、日志或提供方配置。
- 如果误刷新扫描动画或管理后台，重新登录并从“开始扫描”段重录，因为扫描数据只保存在当前会话中。
- 如果回答仍在逐字出现，不要切换模式或继续输入；等引用全部显示后再进行下一步。

## 可选替换问题

- 业务备用：`移动端消费方和渠道提供方在会话更新中各自负责什么？`
- 业务备用：`客户信息和会话令牌在跨仓库更新过程中如何被保存？`
- 技术细节：`UpdateChannelSessionOp 调用 UpdateSessionOp 时设置了哪些 SOFA 参数？`
- 技术细节：`UpdateSessionOp 如何构造 Redis key、写入 token 并提交会话？`
