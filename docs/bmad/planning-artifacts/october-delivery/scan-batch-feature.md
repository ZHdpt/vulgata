## Minimum tool integration

The host owns approved Repository/root/lifetime binding, live authority before use
and disclosure, contained source/result verification and process disposal. Workers
receive only closed relative-path/query tools, never physical roots or commands.
Keep prepared-origin directories stable and source read-only; add no Git acquisition,
source copy or repository-wide hashing prerequisite.

- JDT composition must use the qualified
  [`OpenDedicatedAsync`](../../../../src/dotnet/Vulgata.Infrastructure/Analysis/Java/PreparedJavaNavigationContextFactory.cs),
  not assume the existing composer's guarded `OpenAsync` selects it. Supply the
  application-owned lease, external state root and explicitly configured compatible
  JDK/host policy. Preserve definition/reference semantics and no-import/build/restore
  settings. Actual JDT limitations may use the existing file-tool fallback with
  recorded gaps; this does not approve dropping JDT globally.
- CodeGraph must consume the descriptor returned by
  [`PrepareAsync`](../../../../src/dotnet/Vulgata.Infrastructure/Analysis/CodeGraph/NativeCodeGraphSession.cs)
  for native discovery and `codegraph_explore`. Preserve the pinned qualified host
  profile and closed arguments. Required native CodeGraph is not satisfied by file
  fallback. Its present direct-path excerpt verification needs integration with
  approved contained reads and final live-authority checks.
- Choose a bounded application-controlled profile/session lifetime and same-process
  reuse of the host-owned index, making only necessary adapter changes. Current JDT
  grants cap at 30 seconds; CodeGraph sessions cap at two minutes/ten calls and allow
  one session per descriptor. Disposal leaves `.codegraph`; re-preparation rejects it.
  These are not unlimited batch contracts. No per-Worker index init/delete,
  cross-process borrowing, restart adoption or automatic reclamation is required.
- Positively identify application-owned `.codegraph` state; exclude it from source
  evidence, admission and counts, deny direct ordinary reads, and preserve legitimate
  unowned same-name source. Qualify list/read/search and multi-page continuation under
  the chosen sequencing. Dedicated JDT grants no concurrent CodeGraph preparation or
  cache mutation. Mixed-root coexistence is unfinished integration, not inherited
  qualification; unchanged-source observations are not preventive OS isolation.
