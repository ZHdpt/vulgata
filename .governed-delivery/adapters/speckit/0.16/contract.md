# SpecKit 0.16 definition adapter

This adapter supplies feature activation, specification, planning, task generation, cross-artifact analysis, and append-only convergence.

The consuming repository owns its `.specify` tree and Constitution. The workflow distribution calls the installed skills and scripts but does not copy or modify the upstream SpecKit installation.

## Governed Convergence Override

Governed TDD/direct verification supplies the implementation prerequisite; do not also invoke `speckit-implement`. Root checks prerequisite evidence first and returns known unfinished work to its existing owner. The analyst matches each gap to unfinished tasks by obligation, observable behavior, and defect evidence before append. Reuse covering tasks; a shared requirement alone does not merge distinct defects, and a real completed-task regression needs a traceable correction.

Preserve raw upstream output and separately report governed `converged`, `tasks_appended`, `tasks_reused`, or `return_to_definition`. Mixed reuse/append is `tasks_appended`; reuse remains non-converged. An invalid definition/authority returns to `spec|plan|tasks` before speculative append. Report prerequisite/source evidence, unchanged findings, reused/appended IDs, and before/after task hashes. The only permitted analyst write is genuinely new append-only Convergence tasks preserving prior bytes/IDs; description/dependency edits go to the active definition author. These are distribution-owned routing rules, not claims that SpecKit 0.16 natively implements the extra outcomes. Apply the shared recovery guard; no extra implementation provider or upstream edit.
