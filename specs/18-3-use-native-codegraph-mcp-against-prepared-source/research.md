# Research: Story 18.3 Native CodeGraph MCP

This is source-grounded planning research for the corrected index-placement boundary. The owned standalone CodeGraph 1.5.0 native MCP probe and completed independent client/wrapper work establish transport and controlled behavior, not Vulgata application-bound physical source authorization. Story 18.2's shared source/root lease checkpoint and user authority for any temporary source copy remain unresolved. [Probe](evidence/native-mcp-standalone-01.json); [implementation evidence](evidence/implementation-group-03.json); [current spec](spec.md).

## Decision 1: Consume the F0 prepared-source authority

**Decision**: Consume integrated Story 18.1's exact `PreparedSourceApproval` tuple, mandatory current-authority verifier and three-function read seam without changing them. Story 18.2 owns shared prepared-source/root authority and lease lifetime; Story 18.3 alone owns CodeGraph-specific index placement. **Rationale**: The [Core contracts](../../src/dotnet/Vulgata.Core/DomainServices/PreparedSourceContracts.cs), [issuer](../../src/dotnet/Vulgata.Infrastructure/Source/PreparedSourceContextIssuer.cs), [Agent functions](../../src/dotnet/Vulgata.Agents/WorkerExecution/PreparedSourceFunctions.cs) and [accepted 18.1 contract](../016-contained-source-tools/contracts/prepared-source-tools.md) establish a live, fail-closed approved binding; physical root/handles remain private. **Alternative**: a new 18.3 root registry, fourth 18.1 function or inferred 18.2 copy grant would duplicate/broaden authority; reject. **Open dependency**: no identifiable verified 18.2 lease checkpoint exists in this boundary. [Coordinator invalidation](evidence/index-placement-invalidation-01.json).

## Decision 2: Native tool path

**Decision**: Preserve completed native stdio client and closed Worker wrapper (`ModelContextProtocol.Core` 1.4.1) while holding physical `codegraph init` and `serve --mcp -p <Story 18.3 staging project> --no-watch` for a separately approved placement. **Rationale**: The [standalone probe](evidence/native-mcp-standalone-01.json) observed CodeGraph 1.5.0 `initialize`, `tools/list` and `tools/call`; [raw result](evidence/native-mcp-standalone-01.raw.json) discovered `codegraph_explore` and returned `Calc.cs`/`Caller.cs`. [T001–T005/T009–T010 evidence](evidence/implementation-group-03.json) covers the Vulgata controlled client/wrapper, while [current package manifest](../../Directory.Packages.props) pins the official SDK. Those results used owned writable fixtures and do not authorize a live-root write/copy or prove Vulgata app-bound source access. **Alternative**: CLI query wrapper, CodeGraphContext, raw discovered `AITool` or simulated discovery fail native/authority obligations. **Open verification**: 18.2 lease, Story 18.3 placement, live authority and selected-host integration.

## Decision 3: Scope, lifetime and failure

**Decision**: Qualify discovered `codegraph_explore`, expose only a closed UTF-8 `query` <=512 bytes and integral `maxFiles` 1–12 (default 4), and inject native `projectPath` from trusted physical access. Limit native result to 256 KiB, each call to 30 seconds, and one session to 10 calls/2 minutes; trusted configuration may lower but model input cannot raise those caps. Bind the finite session to the exact approval tuple; reverify current authority before native work and before releasing buffered source/location. Keep CodeGraph counters independent of 18.1 file-tool counters under the same source authority. **Rationale**: The [raw schema](evidence/native-mcp-standalone-01.raw.json) exposes model-supplied `projectPath`; [AD-6/15](../../docs/bmad/planning-artifacts/architecture/ARCHITECTURE-SPINE.md), [O-NFR01/O-AR09](../../docs/bmad/planning-artifacts/october-release-epics.md) and [spec FR-002–FR-009](spec.md) require application binding, cancellation and truthful readiness. Existing CodeGraph process bounds inform the proposed response/call limits. **Alternatives**: unfiltered native tool, model-selected root, shared mutable project session or silent source-only fallback violate authority/truthfulness. **Open verification**: host qualification must confirm these proposed caps preserve useful behavior; any same-binding sharing needs a separate concurrency proof.

## Decision 4: Pinned index placement and authority

**Pinned finding**: Installed `@colbymchenry/codegraph`/`codegraph-win32-x64` 1.5.0 `directory.js` permits `CODEGRAPH_DIR` only as a plain name and `getCodeGraphDir` joins it to the project root; invalid absolute/separator/traversal values fall back to `.codegraph`. Installed `utils.js` and extraction call sites permit `allowSymlinkEscape` for indexing reads, while content sinks use stricter containment. These are inspected local package files (`G:/packages/npm/prefix/node_modules/@colbymchenry/codegraph/node_modules/@colbymchenry/codegraph-win32-x64/lib/dist/directory.js`, SHA-256 `F164E53DB714519B45516A97164D709647110DBE1F15C6C655EDD6DAB2BF02BA`; sibling `utils.js`, SHA-256 `CE085743930D231F92C842DA021416581680775B1C41C1371E218A71ADA82461`). [Upstream issue #986](https://github.com/colbymchenry/codegraph/issues/986) requests external index storage; an open request is not a 1.5.0 capability.

| Option | Security / fidelity / lifetime / cleanup | Disposition |
|---|---|---|
| Isolated regular-file staging project | A Story 18.3-owned disposable tree can contain both regular source files and in-project `.codegraph`, leaving the live root untouched. Proposed initial upper bounds: one Repository, 10,000 regular files, 512 MiB copied bytes, 120 seconds; a cap hit is unavailable/incomplete, never ready partial coverage. Copy only through the verified 18.2 lease; reject symlinks/reparse points, bind exact approval/root identity, detect observed source changes and settle staged source plus index on expiry/cancellation. A live input can change during staging, so no unobserved immutable-snapshot claim follows. Temporary proprietary bytes and disk/time cost are material. | **Conditional recommendation**, only after explicit user authorization for the bounded copy and direct-host qualification. |
| Symlink farm or mount/overlay | A symlink farm risks CodeGraph index reads outside the staged tree (`allowSymlinkEscape`); content sinks differ, and replacement races can break result provenance. A true read-only source mount plus writable project-local index might avoid a copy, but Windows direct-host mount/overlay privileges, CodeGraph traversal behavior and cleanup are unproved. | Reject symlink farm as default. Reconsider an independently qualified mount only through another reviewed design/authority decision. |
| Direct operator-root write | Native init works in-place but creates/retains `.codegraph` under operator-prepared source and violates current unchanged-root FR-010/SC-007. Cleanup after the fact does not erase the unauthorized mutation window or failure residue. | Reject under current spec; a user-approved spec/architecture change would be required. |
| Explicit unavailable / deferral | No extra source copy or live-root write; 18.1 reads still work. Required native CodeGraph remains unavailable and O-FR05/Story 18.3 cannot complete. | Correct fail-closed outcome if copy is declined and no zero-copy route is proven. |

**Decision needed**: After independent plan review, the user must authorize or decline a finite temporary copy into a Story 18.3-owned disposable project, with the stated source/fidelity/cleanup limits. This is separate from prior delegated planned-change and implementation approvals and does not waive the 18.2 checkpoint, affected plan/tasks review or native host qualification. Silence authorizes no copy. If the user retains zero-copy, root reports unavailable/deferral or initiates a new reviewed design when a real external-index capability becomes available. [Spec FR-010/SC-007](spec.md); [AGENTS.md delegation limits](../../AGENTS.md).

## Authority and compatibility

The [Constitution](../../.specify/memory/constitution.md) places tool/process adaptation in Infrastructure and bounded agent execution behind injected contracts. [October proposal item 11](../../docs/bmad/planning-artifacts/sprint-change-proposal-2026-09-26-october-batch-release.md) selects direct host execution; Docker application/tool packaging and qualification are outside this release. Story 18.2 owns shared root/lease authority; Story 18.3 owns any CodeGraph staging/index. Completed independent client/wrapper work remains valid, while physical-root tasks require an explicit user copy decision, the verified 18.2 checkpoint, affected plan/tasks review and later native host qualification. The [callable-seam lesson](../../docs/project-lessons.md) protects the already built public seam; the [launcher lesson](../../docs/project-lessons.md) prevents misclassifying Windows sandbox access denial as product failure. No database migration, general MCP registry, JDT-LS work or provider call is planned. Historical revision-bound CLI/JSON contracts remain their own scope. If no safe placement is authorized, the user decides deferral or a changed scope; the runner must not advance the held physical tasks by assumption.
