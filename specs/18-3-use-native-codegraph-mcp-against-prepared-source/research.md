# Research: Story 18.3 Native CodeGraph MCP

This is source-grounded planning research. An owned standalone CodeGraph 1.5.0 native MCP probe passed, but Vulgata Agent integration, exact source authorization and Story 18.2's shared trusted-workspace checkpoint remain unqualified. [Probe](evidence/native-mcp-standalone-01.json); [current spec](spec.md).

## Decision 1: Consume the F0 prepared-source authority

**Decision**: Consume integrated Story 18.1's exact `PreparedSourceApproval` tuple, mandatory current-authority verifier and three-function read seam without changing them. **Rationale**: Its [Core contracts](../../src/dotnet/Vulgata.Core/DomainServices/PreparedSourceContracts.cs), [issuer](../../src/dotnet/Vulgata.Infrastructure/Source/PreparedSourceContextIssuer.cs), [Agent functions](../../src/dotnet/Vulgata.Agents/WorkerExecution/PreparedSourceFunctions.cs) and [accepted contract](../016-contained-source-tools/contracts/prepared-source-tools.md) establish a live, fail-closed approved binding; physical root/handles remain private. **Alternative**: a new 18.3 root registry or fourth 18.1 function would duplicate/broaden authority; reject. **Open dependency**: Story 18.2 owns the shared trusted physical-workspace contract and focused tests, but its identifiable verified checkpoint is not yet available. Story 18.3 cannot invent a substitute lease/interface.

## Decision 2: Native tool path

**Decision**: Use CLI `codegraph init` for preparation and local stdio `codegraph serve --mcp -p <contained tool workspace> --no-watch` for native discovery/invocation, mediated by Story 18.3's bounded wrapper after the shared owner establishes safe source-bound workspace/index placement. **Rationale**: The [standalone probe](evidence/native-mcp-standalone-01.json) observed CodeGraph 1.5.0 `initialize`, `tools/list` and `tools/call`; [raw result](evidence/native-mcp-standalone-01.raw.json) discovered `codegraph_explore` and returned `Calc.cs`/`Caller.cs`. `codegraph init` writes `.codegraph` state into its project tree; the probe used an owned writable fixture and does not authorize a write to operator-prepared live source or an unapproved copy. The [official .NET MAF guidance](https://learn.microsoft.com/en-us/agent-framework/agents/tools/local-mcp-tools) shows MCP C# SDK stdio transport, asynchronous client creation and tool discovery, while the [manifest](../../Directory.Packages.props) has MAF 1.13.0 but no explicit `ModelContextProtocol` package. **Alternatives**: CLI query wrapper, CodeGraphContext, raw discovered `AITool` or simulated discovery do not satisfy both native and authority boundaries; writing live source or duplicating it is not an authorized workaround. **Open verification**: pin compatible client package/API, obtain 18.2's verified workspace/index placement and prove Vulgata Agent integration in its selected host.

## Decision 3: Scope, lifetime and failure

**Decision**: Qualify discovered `codegraph_explore`, expose only a closed UTF-8 `query` <=512 bytes and integral `maxFiles` 1–12 (default 4), and inject native `projectPath` from trusted physical access. Limit native result to 256 KiB, each call to 30 seconds, and one session to 10 calls/2 minutes; trusted configuration may lower but model input cannot raise those caps. Bind the finite session to the exact approval tuple; reverify current authority before native work and before releasing buffered source/location. Keep CodeGraph counters independent of 18.1 file-tool counters under the same source authority. **Rationale**: The [raw schema](evidence/native-mcp-standalone-01.raw.json) exposes model-supplied `projectPath`; [AD-6/15](../../docs/bmad/planning-artifacts/architecture/ARCHITECTURE-SPINE.md), [O-NFR01/O-AR09](../../docs/bmad/planning-artifacts/october-release-epics.md) and [spec FR-002–FR-009](spec.md) require application binding, cancellation and truthful readiness. Existing CodeGraph process bounds inform the proposed response/call limits. **Alternatives**: unfiltered native tool, model-selected root, shared mutable project session or silent source-only fallback violate authority/truthfulness. **Open verification**: host qualification must confirm these proposed caps preserve useful behavior; any same-binding sharing needs a separate concurrency proof.

## Authority and compatibility

The [Constitution](../../.specify/memory/constitution.md) places tool/process adaptation in Infrastructure and bounded agent execution behind injected contracts. [October proposal item 11](../../docs/bmad/planning-artifacts/sprint-change-proposal-2026-09-26-october-batch-release.md) selects direct host execution; Docker application/tool packaging and qualification are outside this release. Under the revised [spec Delivery Sequencing](spec.md), accepted plan review and planned-change authorization permit independent native client/wrapper/controlled-test tasks; accepted complete-definition review and implementation approval permit their implementation. Story 18.2 owns the shared physical workspace; physical-root preparation/integration, application-bound native invocation and Vulgata qualification wait for its identifiable verified checkpoint, affected plan/tasks reconciliation and independent review. The [callable-seam lesson](../../docs/project-lessons.md) requires explicit inputs/methods/results/disposal/cancellation before behavioral TDD; the [launcher lesson](../../docs/project-lessons.md) prevents misclassifying Windows sandbox ancestor access denial as product failure. No database migration, general MCP registry, JDT-LS work or provider call is planned. Historical revision-bound CLI/JSON contracts remain their own scope. A mismatch with the 18.2 checkpoint or actual native client support returns affected work to plan and independent review, preserving valid independent work.
