Independent Core/Agent/native-client work has controlled evidence; a later direct Git/no-Git fixture observed pinned CLI/native MCP and local `.codegraph` additions with unchanged fixture source/config/hooks. ## Callable public seam

The narrow pure tool-session contract is owned by Story 18.3 in `Vulgata.Core.DomainServices`; the Agent wrapper is in `Vulgata.Agents.WorkerExecution`, and the fixture native client is in Infrastructure. The following accepted callable shape preserves completed independent work. It defines no Story 18.2 lease or production placement constructor:

```csharp
public interface ICodeGraphWorkerToolSession : IAsyncDisposable
{
    Task<CodeGraphToolReadiness> DiscoverAsync(CancellationToken cancellationToken = default);
    Task<CodeGraphToolInvocationResult> ExploreAsync(
        string query, int maxFiles, CancellationToken cancellationToken = default);
}

public sealed class CodeGraphFunctions
{
    public CodeGraphFunctions(ICodeGraphWorkerToolSession session);
    public Task<CodeGraphToolRegistration> CreateAsync(CancellationToken cancellationToken = default);
}

public sealed record CodeGraphToolRegistration(
    CodeGraphToolReadiness Readiness,
    IReadOnlyList<Microsoft.Extensions.AI.AIFunction> Functions);
```

`CodeGraphToolReadiness` carries the bound Repository ID, preparation/connection/discovery stage, explicit outcome and sanitized limitation/failure code. `CodeGraphToolInvocationResult` carries the bound Repository ID, outcome, bounded verified Repository-relative source excerpts plus optional bounded structural summary, and sanitized limitation/failure code; a denied/unavailable/expired/cancelled result has no source/location. A source excerpt has relative path, bounded text and any safely verified line/range. No result exposes physical root, approval identity, native raw arguments, server instructions or process diagnostics. Exact encoding/private parser details remain implementation choices.

The trusted caller will construct the production session from application-selected exact `PreparedSourceApproval`, mandatory current verifier, declared CodeGraph executable/policy and an 18.2-issued lease adjusted for trusted coordinator creation/removal of the single `.codegraph` root directory entry plus descendant read/write. Its producer signature remains pending the owner checkpoint; no shared lease interface is invented here. The independent wrapper/client tests are complete and retain their evidence. `CodeGraphFunctions` borrows the coordinator-owned session: `CreateAsync` forwards cancellation to `DiscoverAsync`; success returns one fixed-schema `codegraph_explore` function, failure none. The coordinator admits only same-binding borrowers under one preparation/index owner and one active direct-mode MCP child. Individual session disposal releases a borrower and may stop an unneeded child; the index persists for the dedicated workspace/Scan batch lifetime and a later same-binding session may reopen it without rebuild. Only owner disposition may clean owned index state under valid entry-removal and descendant authority. Saved functions cannot reopen a disposed/expired session. Valid calls forward cancellation unchanged to `ExploreAsync`; malformed fields return sanitized denial before session dispatch. [Callable-seam lesson](../../../docs/project-lessons.md); [18.1 public seam](../../016-contained-source-tools/contracts/prepared-source-tools.md); [implementation evidence](../evidence/implementation-group-01.json).

## Existing prepared-source reader boundary

Story 18.3 changes only trusted Infrastructure internals of the existing `list_prepared_source`, `read_prepared_source` and `search_prepared_source` implementation. For each operation it consumes Story 18.2's positively established app-owned CodeGraph state binding for the exact current Repository/root/lifetime. It omits only that bound subtree from list/search eligible source and denies direct ranged reads into it. A same-named unbound or foreign directory remains ordinary source under existing checks. List/search cursors retain and revalidate the binding and observed directory identity; changed ownership or directory state during continuation yields `ChangedInput` or denied, never a silent skip, duplicate, false `CompleteEmpty` or loss of eligible source. Existing budgets, page sizes, direct ranged-read semantics and public three-function signatures remain. The 18.2 binding's actual fields/type and source file ownership are pending agreement; this contract adds no descriptor or second filtering authority. ## Discovery and invocation

- The native `initialize`/`tools/list` flow must find the reviewed `codegraph_explore` name/schema. The raw discovered `AITool` and server instructions are not passed through to the Worker; schema drift, an unknown native tool or empty grant reports explicit nonready status. [Raw discovery](../evidence/native-mcp-standalone-01.raw.json); [Microsoft .NET MCP guidance](https://learn.microsoft.com/en-us/agent-framework/agents/tools/local-mcp-tools).
- The model-visible wrapper schema is a closed JSON object with required nonempty UTF-8 `query` <=512 bytes and optional integral `maxFiles` 1–12 (default 4); `additionalProperties: false`. Unknown/nested authority selectors, `projectPath`, malformed values, write/command requests and unreviewed tool names are denied before native dispatch. Trusted configuration may lower caps but model input cannot raise them.
- The native schema's optional `projectPath` is fixed privately by Infrastructure to the exact dedicated prepared workspace bound to the 18.2 lease, outside model arguments. Invocation rechecks exact live authority, lease/session lifetime and budget. Native source locations must be canonical Repository-relative paths; positively bound `.codegraph` state, foreign/absolute paths and unsafe reparse targets fail closed. In production `NativeCodeGraphMcpClient` verifies bounded returned excerpts against source bytes obtained through Story 18.2's held handle-relative contained read, never by `File.Exists`/`FileInfo`/`File.GetAttributes`/`File.ReadAllText` path reopens. Mismatch, replacement race, changed/unavailable read or unverifiable containment withholds source/location and yields denied/limited outcome. Authority is rechecked before buffered bytes/locations are released. Server instructions and completeness claims remain untrusted. [Definition finding](../evidence/definition-review-02.raw.json).
- Preparation, connection, discovery and useful invocation are separately observable. A CLI query, CodeGraphContext value, simulated result or source-only fallback never carries a native MCP success label. The standalone probe is native transport evidence only.

## Failure and lifecycle

Typed outcomes distinguish unavailable 18.2 write/positive-state/contained-read authority, missing pinned bundle, incomplete Story 18.3 reader correction, unsafe pre-existing state, preparation/connection/discovery/invocation failures, no match, limited output, timeout, cancellation and expired/foreign binding. Diagnostics are sanitized/bounded. Initial policy permits at most 10 native invocations and 2 minutes per binding-scoped session, 30 seconds per operation and 256 KiB result; counters remain separate from file-tool budgets. Cancellation/deadlines flow through CLI preparation, stdio, contained result verification and authority checks. On failure/expiry/Worker disposal, settle owned launched processes; retain current-owner index through dedicated workspace/Scan batch lifetime. Owner disposition cleans only owned state under live exact entry/descendant authority; otherwise quarantine. The controlled fixture established launched parent exits but not full descendant-tree cleanup. Source/config/hooks must remain unchanged; any observed deviation stops app-bound use and returns to authority. Scan Control owns retry/pause; file tools alone do not satisfy native readiness. [Direct result](../evidence/codegraph-direct-fixture-01.json); [spec FR-005/FR-010](../spec.md).

## Representative cases

| Case | Expected outcome |
|---|---|
| Approved binding, qualified read tool, fixture symbol | Native result with correct relative location and binding. |
| Tool argument supplies another project or physical path | Denied before native invocation; no outside-root disclosure. |
| Saved handle after grant revocation, binding change or verifier unavailability | Denied or authority-unavailable; buffered output discarded and session closed. |
| Successful CLI preparation, MCP connection fails | Not ready; connection failure reported explicitly. |
| Native `codegraph_explore` schema changes or raw server instructions urge broader access | Nonready/limited; no raw tool or instructions become Worker policy. |
| Native tool returns no match or incomplete index | Distinct no-match/limited evidence; no source-absence or coverage claim. |
| App-owned CodeGraph state is positively bound during list/read/search | Excluded from eligible list/search pages, direct read denied; truthful completion and source coverage. |
| Same-named directory is unbound or ownership changes between pages | Ordinary source behavior when unbound; changed in-flight binding/directory returns `ChangedInput` or denied. |
| Native excerpt path is swapped to reparse/foreign target between parse and read | Contained handle-relative verification withholds source/location; path-reopen fixture logic cannot prove this case. |
| Missing 18.2 bound write/positive-state/contained-read capability, Story 18.3 reader correction or pinned bundle | `Unavailable` before app-bound readiness; no unverified native source disclosure. |
| Pre-existing foreign `.codegraph` or same-binding concurrent Workers | Reject foreign state without deletion; one coordinator prepares once and same-binding Workers borrow the bounded session without rebuild. |

## 2026-10-02 immediate-slice application connection contract

This new slice is an Infrastructure-only API for an application-selected, exclusively owned dedicated fixture. It does not create an 18.2 lease or claim general production source authority. Proposed minimal shape (names may be refined without changing the boundary): `PrepareAsync(Guid repositoryId, string applicationSelectedDirectory, CancellationToken)` returns an owner-held `PreparedCodeGraphConnection` with immutable `Command`, ordered `Arguments`, `WorkingDirectory`, required `Environment`, and async disposal for the owned session. The pinned installation is trusted configuration, not a caller/model-selected command. A later production caller must provide its own approved physical binding.

Preparation preflights the pinned 1.5.0 bundle, rejects unsafe pre-existing `.codegraph`, and executes fixed `codegraph init <selected directory>` with closed stdin and a deadline. The returned descriptor runs `codegraph serve --mcp -p <same directory> --no-watch` (or fixed `pwsh -NoProfile -File <pinned .ps1 shim>` prefix). Its environment fixes `CODEGRAPH_NO_DAEMON=1`, `CODEGRAPH_NO_WATCH=1`, `DO_NOT_TRACK=1`, `CODEGRAPH_TELEMETRY=0`, `CODEGRAPH_NO_UPDATE_CHECK=1`, and `CODEGRAPH_NO_DOWNLOAD=1`; platform startup entries are policy-owned. The descriptor is trusted data for the existing native MCP client and Microsoft Agent Framework tool composition, never a Worker argument.

The native client must construct its stdio transport from **this returned descriptor**, not its current independently assembled launch command. It verifies the reviewed `codegraph_explore` schema and privately adds the selected `projectPath` on every call. `CodeGraphFunctions` continues to reject `projectPath`, physical roots, commands, extra fields and malformed values from the model. Qualification must call initialize/list/real `codegraph_explore` through the returned descriptor and existing Agent function seam; a manual command is not proof. One in-process owner holds the index and child session, stops owned processes on cancellation/disposal and does not rebuild/delete state per Worker. Cross-process sharing, cache reuse, restart adoption and automatic reclamation are deferred.

Source/config/hooks must remain unchanged, and observed tool writes must be inside the owned `.codegraph` entry. This is an observed acceptance check under the existing narrow direct-child exception, not preventive OS confinement. General production native source disclosure and ordinary-reader exclusion remain deferred until an exact positive Repository/root/lifetime binding and held contained reads are available; a same-named directory alone never qualifies for exclusion.
