## Implementation Design

### Responsibilities

- **ID-R01**: The integrated Story 18.1 owns `PreparedSourceApproval`'s exact batch, Repository, subject, `WorkerSourceRead` purpose, approval identity and root-binding identity, live `IPreparedSourceCurrentAuthorityVerifier`, and the public three-function `PreparedSourceFunctions` read seam. Story 18.3 consumes that authority but neither modifies its issuer/read context/functions nor adds a fourth 18.1 function. [Core contract](../../src/dotnet/Vulgata.Core/DomainServices/PreparedSourceContracts.cs); [18.1 contract](../016-contained-source-tools/contracts/prepared-source-tools.md).
- **ID-R02**: Infrastructure owns declared CodeGraph preparation, native MCP process/client lifecycle and result containment; Agents presents the granted surface to the Worker; Web composes. Scan Control retains wider scheduling and retry authority.
- **ID-R03**: For the observed CodeGraph 1.5.0 surface, application policy grants only native `codegraph_explore` after validating discovery name/schema. The Agent receives a fixed-description wrapper with a closed `query`/bounded `maxFiles` schema; it never receives the raw discovered `AITool`, its `projectPath` parameter or the MCP server's advisory instructions. Unknown/new native tools require separate qualification and grant review. [Raw probe](evidence/native-mcp-standalone-01.raw.json); [Microsoft guidance](https://learn.microsoft.com/en-us/agent-framework/agents/tools/local-mcp-tools).

### Interfaces

- **ID-I01**: Trusted composition passes the existing `PreparedSourceApproval` and mandatory `IPreparedSourceCurrentAuthorityVerifier` to the Story 18.3 runtime; the current approval must equal the exact requested tuple at session creation, operation start and immediately before disclosure. The existing `PreparedSourceGrantRequest.PhysicalRootPath` is private trusted input to 18.1 issuance, not an Agent property or a grant for CodeGraph. Story 18.3 obtains physical access only through the separately owned, verified shared trusted-workspace checkpoint; its precise callable type remains pending and cannot be fabricated here. [Core contract](../../src/dotnet/Vulgata.Core/DomainServices/PreparedSourceContracts.cs); [18.1 contract](../016-contained-source-tools/contracts/prepared-source-tools.md).
- **ID-I02**: The Worker-facing `codegraph_explore` wrapper accepts only nonempty UTF-8 `query` <=512 bytes and optional integral `maxFiles` 1–12 (default 4); `additionalProperties: false` rejects `projectPath`, nested selectors, unknown fields and malformed types before native invocation. The trusted adapter fixes native `projectPath` to the verified Story 18.2 contained tool workspace bound to the approved root, and launch uses only the declared executable/workspace. Results carry sanitized status, Repository-relative locations, <=256 KiB bounded source and explicit limitations. Trusted configuration may lower but never model-raise these caps. [Raw schema](evidence/native-mcp-standalone-01.raw.json); [AD-6](../../docs/bmad/planning-artifacts/architecture/ARCHITECTURE-SPINE.md).
- **ID-I03**: Use `codegraph init` for preparation and local stdio `codegraph serve --mcp -p <contained tool workspace> --no-watch` for native initialize/list/call, conditional on Story 18.2 providing a verified source-bound writable tool-state location. The owned fixture probe used its own writable root; it does not authorize these commands against an operator-prepared live root. Official .NET guidance demonstrates MCP C# SDK stdio transport, asynchronous client creation and tool listing; pin/verify the exact compatible package/API during implementation because the manifest has no explicit MCP SDK. Raw native tools are adapted, never handed directly to the Agent. CLI query, CodeGraphContext or simulated calls never carry a native success label. [Probe](evidence/native-mcp-standalone-01.json); [Microsoft guidance](https://learn.microsoft.com/en-us/agent-framework/agents/tools/local-mcp-tools); [package manifest](../../Directory.Packages.props).
- **ID-I04**: Define a Story 18.3-only public callable seam: `ICodeGraphWorkerToolSession : IAsyncDisposable` in Core exposes `DiscoverAsync(CancellationToken)` returning typed `CodeGraphToolReadiness` and `ExploreAsync(string query, int maxFiles, CancellationToken)` returning typed sanitized `CodeGraphToolInvocationResult`; `CodeGraphFunctions(ICodeGraphWorkerToolSession)` in Agents exposes `CreateAsync(CancellationToken)` returning readiness plus either exactly one fixed-schema `AIFunction` or no function on failure. Trusted composition creates and owns/disposes the session; the Agent wrapper borrows it, forwards cancellation unchanged and never accepts an approval/root/command argument. [Consumer contract](contracts/native-codegraph-boundary.md); [18.1 callable-seam lesson](../../docs/project-lessons.md).
- **ID-I05**: The Infrastructure session producer must receive the exact application-selected approval/current-authority verifier, declared CodeGraph executable/policy bounds and Story 18.2's shared trusted physical-workspace capability, including qualified writable `.codegraph` tool-state placement. Its public construction signature cannot be finalized until an identifiable Story 18.2 checkpoint defines/verifies that contract; no substitute lease, direct reuse of 18.1's private handles, live-root write or source duplication is authorized. Tasks may describe independent native client/wrapper/controlled-session slices after accepted plan review and planned-change authorization; their implementation requires accepted complete-definition review and implementation approval. Physical-root preparation/integration, application-bound native invocation and Vulgata host qualification remain blocked until the verified checkpoint, affected plan/tasks reconciliation and independent review. [Current spec delivery sequencing](spec.md).

### State and Lifetime

- **ID-S01**: One finite native session binds the exact `PreparedSourceApproval` tuple and the shared owner's contained root identity; no process-global current project crosses roots. Any changed/revoked approval or root-binding identity, verifier unavailability, expired session or lost physical-access validity latches it closed, discards buffered output and requires a fresh grant. The caller disposes the borrowed Agent wrapper's session after all calls settle; concurrent roots cannot inherit one another's connection/index/output.
- **ID-S02**: Index/session/process state stays disposable, separate from 18.1's live source context and canonical Knowledge. Record preparation, native connection, schema-checked discovery and useful invocation separately. The observed standalone smoke records CodeGraph 1.5.0 native transport, not Vulgata readiness; an empty result or index-success does not prove completeness or permanent identity.
- **ID-S03**: Because `codegraph init` creates `.codegraph` state in its target project tree, production preparation and `projectPath` must target a contained tool workspace whose writable index state is separated from the operator-prepared live source. Story 18.2's shared contract must establish source identity, read containment, approved lifetime and safe tool-state placement without assuming permission to copy or mutate source. Until its verified checkpoint proves such a placement, physical preparation/invocation is blocked and the plan returns for feasibility correction if the owner cannot supply it.

### Async and Cancellation

- **ID-A01**: `CreateAsync`/`DiscoverAsync` and tool invocation forward caller cancellation to native preparation, stdio connection, list/call and authority checks, linked to finite policy deadlines. Immediately before returning any buffered source, await `VerifyCurrentAsync` for the exact tuple; cancellation, verifier loss or expiry discards output. Dispose the owned MCP client/stdio child and shared physical-access usage through its eventual owner contract, without stopping unrelated processes.
- **ID-A02**: Isolate or serialize operations until CodeGraph client/server multiplexing is qualified. Start with one finite binding-scoped session, <=10 invocations and <=2 minutes total lifetime, independent of 18.1's file-tool counters; each operation has a <=30-second deadline. Share/coalesce only with a proven same-binding policy. Server advisory call budgets are untrusted text, not enforcement.

### Failure and Retry

- **ID-F01**: Return distinct sanitized outcomes for missing/unprepared source, unavailable installation, preparation, connection, missing/changed native tool schema, invocation, timeout, cancellation, authority denied/unavailable, session expiry and bounded/incomplete result. No-match is distinct from incomplete index. Ready requires successful native discovery of the qualified tool; successful invocation is separate evidence.
- **ID-F02**: Required CodeGraph failure never silently selects source-only analysis. Authorized 18.1 file tools may be used independently. The adapter performs no hidden retry; Scan Control applies its existing bounded retry/pause policy. [AD-15](../../docs/bmad/planning-artifacts/architecture/ARCHITECTURE-SPINE.md).
- **ID-F03**: Native `codegraph_explore` may return verbatim source, paths and server-authored advisory text. Treat all native descriptions/instructions/content as untrusted data: never forward server instructions as Worker policy; verify result source against the current approved root and recheck authority before disclosure. Deny results whose containment cannot be proved, or return explicit bounded/redacted limitations. Do not disclose absolute paths, outside-root source, raw arguments, secrets or unbounded stderr.
- **ID-F04**: If the shared workspace cannot provide safe writable index state tied to the approved source without modifying or duplicating operator input, report a preparation-unavailable/blocking integration outcome. Do not run `codegraph init` against the live root, fall back to a CLI query or fabricate readiness; return the placement/ownership conflict to plan and integration coordination.

### Reuse and Locality

- **ID-L01**: Reuse existing CodeGraph configuration/process patterns only where they satisfy prepared-origin native behavior. Preserve historical revision-bound CLI/JSON invariants; do not broaden them by relabelling a CLI reply as native MCP.
- **ID-L02**: Keep native adaptation by Infrastructure CodeGraph code, a narrow pure tool-session contract in Core, the fixed Worker `AIFunction` wrapper in Agents and composition in Web. Reuse 18.1's exact authority verifier semantics and three-function seam without changing them. Consume Story 18.2's verified shared physical-workspace checkpoint without JDT-LS coupling; no generic MCP framework, extra service, schema or provider call is required.

### Test Seams

- **ID-T01**: Public-seam tests construct `CodeGraphFunctions` with a controlled `ICodeGraphWorkerToolSession`, call `CreateAsync`, inspect exactly one fixed `codegraph_explore` schema, and invoke it with valid `query`/`maxFiles`, malformed input, `projectPath` and nested selector attempts. Assert invalid calls never reach the session; valid calls forward cancellation and sanitized results; caller-owned disposal and closed-session calls do not reopen source. These tests are not native qualification. [Callable-seam lesson](../../docs/project-lessons.md).
- **ID-T02**: The owned standalone probe already records CodeGraph 1.5.0, `codegraph_explore` discovery and real `Calc.cs`/`Caller.cs` source. Later Vulgata integration must use the selected host and approved fixture to prove production Agent discovery/invocation, correct-root/foreign-root behavior, exact live authority at result release, honest failures and owned cleanup. Independently authorized 18.1 file tools remain possible; no provider/model call is needed. [Probe](evidence/native-mcp-standalone-01.json); [story acceptance](../../docs/bmad/planning-artifacts/october-release-epics.md).
- **ID-T03**: Verify exact 18.1 approval/revocation/unavailability semantics in controlled revocation, changed root/approval, expired session and concurrent-root cases; assert no buffered source/location release after loss and no 18.1 grant expansion. Before physical-root integration, inspect Story 18.2's verified checkpoint for contained source identity, lifetime and writable `.codegraph` placement without live-root mutation or unauthorized copy; then rerun affected plan/independent review, behavior and native host gates. [18.1 contract](../016-contained-source-tools/contracts/prepared-source-tools.md); [spec SC-006](spec.md).
- **ID-T04**: Run process/root tests through the qualified direct-host launcher with owned fixtures and explicit permissions; a Windows ancestor `NtCreateFile` access-denied in the Codex sandbox is an execution-permission boundary until diagnosed, not proof of a product containment defect. Report focused and full-suite evidence separately. [Launcher lesson](../../docs/project-lessons.md).

### Alternatives

- **ID-X01**: CLI-query-to-tool wrapping or CodeGraphContext reuse would be shorter but cannot prove native MCP discovery/invocation and fails O-FR05/FR-13.1; reject.
- **ID-X02**: Model-selected physical roots or exposing all discovered native tools would simplify wrapping but violate application authority and O-NFR01; reject.
- **ID-X03**: One mutable current-project MCP session may save startup cost but makes cross-root and revocation isolation hard to prove; start with binding-scoped sessions and revisit only with evidence.

### Consequences

- **ID-C01**: This is a Worker-visible agent-tool and material Scan preparation/use change. AGENTS.md requires independent plan review and planned-change authorization before tasks. Delivery then proceeds through the ordinary accepted-definition, implementation-approval and verification gates; no plan review alone authorizes implementation.
- **ID-C02**: The allowlist may exclude new useful native tools until reviewed, and binding-scoped sessions may add startup cost. Those limitations are preferable to false coverage or cross-root reuse claims.
- **ID-C03**: Story 18.1 is integrated and verified, and standalone native CodeGraph 1.5.0 smoke passed on a writable owned fixture. Neither proves Vulgata Worker integration/authorization or safe production `.codegraph` placement. Story 18.2's shared trusted physical-workspace checkpoint has not yet been identified and verified. The reviewed definition may later support gated independent client/wrapper/controlled-test tasks and implementation, but no physical-root preparation/integration, application-bound native invocation or Vulgata qualification may execute before the checkpoint is reconciled into the affected plan/tasks and independently reviewed.

## Self-Review

The plan retains one owner per boundary: Story 18.1 exact source authority and three file functions, Story 18.2 shared trusted physical workspace, Story 18.3 native CodeGraph adaptation and bounded Agent wrapper, Web composition and Scan Control scheduling. The invariant is current exact application-selected approval/root binding at native discovery, invocation and disclosure, with source withheld if authority is revoked, changed or unavailable. The public Story 18.3 callable seam names construction input, methods, result shapes, borrowed session disposal, cancellation and closed model arguments, addressing the [callable-seam lesson](../../docs/project-lessons.md). The pending Infrastructure producer signature is confined to physical integration; independent client/wrapper tasks are definable after the pre-task gates and implementable only after accepted complete-definition review and implementation approval. A finite binding-scoped lifetime and separate CodeGraph budgets make concurrency testable without expanding 18.1 grants. `codegraph init` writes `.codegraph` state, so safe writable tool-state placement is a concrete feasibility condition on the 18.2 checkpoint; the standalone writable fixture neither grants a live-root write nor justifies copying source. October direct-host qualification and the [launcher lesson](../../docs/project-lessons.md) require controlled launcher/permissions evidence, not a sandbox failure misdiagnosed as product failure. No schema migration, general MCP registry or rewrite of historical Git-bound CLI behavior is proposed. Standalone 1.5.0 native proof makes transport plausible, while the 18.2 checkpoint and Vulgata Agent authorization remain unproved; an incompatible shared contract returns affected physical integration to this plan and independent review. This sequence matches the revised spec and resolves PR-18-3-01's plan/spec conflict without treating a missing checkpoint as fulfilled.
