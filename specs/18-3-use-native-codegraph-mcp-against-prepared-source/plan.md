## Implementation Design

### Responsibilities

- **ID-R01**: The integrated Story 18.1 owns `PreparedSourceApproval`'s exact batch, Repository, subject, `WorkerSourceRead` purpose, approval identity and root-binding identity, live `IPreparedSourceCurrentAuthorityVerifier`, and the public three-function `PreparedSourceFunctions` read seam. Story 18.3 consumes that authority but neither modifies its issuer/read context/functions nor adds a fourth 18.1 function. [Core contract](../../src/dotnet/Vulgata.Core/DomainServices/PreparedSourceContracts.cs); [18.1 contract](../016-contained-source-tools/contracts/prepared-source-tools.md).
- **ID-R02**: Infrastructure owns declared CodeGraph preparation, native MCP process/client lifecycle, CodeGraph-specific disposable project/index placement and result containment; Agents presents the granted surface to the Worker; Web composes. Story 18.2 retains shared prepared-source/root authority and lease lifetime, and Scan Control retains wider scheduling/retry authority.
- **ID-R04**: Story 18.3 may construct a CodeGraph staging project only from an 18.2-issued source/root lease and only after an explicit user decision authorizes any bounded temporary copy. It owns staging/index cleanup and must not widen the lease, write the operator-prepared live root or create a competing source authority. If the lease/permission cannot support safe staging, report unavailable rather than improvise placement. [Spec FR-010](spec.md).
- **ID-R03**: For the observed CodeGraph 1.5.0 surface, application policy grants only native `codegraph_explore` after validating discovery name/schema. The Agent receives a fixed-description wrapper with a closed `query`/bounded `maxFiles` schema; it never receives the raw discovered `AITool`, its `projectPath` parameter or the MCP server's advisory instructions. Unknown/new native tools require separate qualification and grant review. [Raw probe](evidence/native-mcp-standalone-01.raw.json); [Microsoft guidance](https://learn.microsoft.com/en-us/agent-framework/agents/tools/local-mcp-tools).

Story 18.3 obtains physical access only through the separately owned, verified shared trusted-workspace checkpoint; its precise callable type remains pending and cannot be fabricated here. - **ID-I02**: The Worker-facing `codegraph_explore` wrapper accepts only nonempty UTF-8 `query` <=512 bytes and optional integral `maxFiles` 1–12 (default 4); `additionalProperties: false` rejects `projectPath`, nested selectors, unknown fields and malformed types before native invocation. The trusted adapter fixes native `projectPath` to the separately approved, disposable CodeGraph staging project bound to the 18.2 source lease, never a model path or bare live root. Results carry sanitized status, Repository-relative locations, <=256 KiB bounded source and explicit limitations. Trusted configuration may lower but never model-raise caps. [Raw schema](evidence/native-mcp-standalone-01.raw.json); [AD-6](../../docs/bmad/planning-artifacts/architecture/ARCHITECTURE-SPINE.md).
- **ID-I03**: The installed `ModelContextProtocol.Core` 1.4.1 and the owned native client already implement the observed local stdio initialize/list/call against a trusted, preprepared owned fixture. Pinned 1.5.0 `CODEGRAPH_DIR` is a single in-project name, not an external index path; no environment/CLI override can be assumed to move it. Raw native tools are adapted, never handed directly to the Agent. - **ID-I04**: Define a Story 18.3-only public callable seam: `ICodeGraphWorkerToolSession : IAsyncDisposable` in Core exposes `DiscoverAsync(CancellationToken)` returning typed `CodeGraphToolReadiness` and `ExploreAsync(string query, int maxFiles, CancellationToken)` returning typed sanitized `CodeGraphToolInvocationResult`; `CodeGraphFunctions(ICodeGraphWorkerToolSession)` in Agents exposes `CreateAsync(CancellationToken)` returning readiness plus either exactly one fixed-schema `AIFunction` or no function on failure. Trusted composition creates and owns/disposes the session; the Agent wrapper borrows it, forwards cancellation unchanged and never accepts an approval/root/command argument. [Consumer contract](contracts/native-codegraph-boundary.md); [18.1 callable-seam lesson](../../docs/project-lessons.md).
- **ID-I05**: The Infrastructure session producer must receive the exact application-selected approval/current-authority verifier, declared executable/policy bounds and the verified Story 18.2 shared source/root lease. Story 18.3's placement adapter, not 18.2, must provide a safely writable in-project index location to the native client. Its construction signature remains pending the real 18.2 contract and the user placement decision; no substitute lease, direct reuse of 18.1 private handles, live-root write or unapproved source copy is authorized. Completed T001–T005/T009–T010 remain valid controlled work; T006–T008/T011–T013 are held for affected plan/tasks review before execution. [Current spec sequencing](spec.md); [tasks](tasks.md).

### State and Lifetime

- **ID-S01**: One finite native session binds the exact `PreparedSourceApproval` tuple and the shared owner's contained root identity; no process-global current project crosses roots. Any changed/revoked approval or root-binding identity, verifier unavailability, expired session or lost physical-access validity latches it closed, discards buffered output and requires a fresh grant. The caller disposes the borrowed Agent wrapper's session after all calls settle; concurrent roots cannot inherit one another's connection/index/output.
- **ID-S02**: Index/session/process state stays disposable, separate from 18.1's live source context and canonical Knowledge. Record preparation, native connection, schema-checked discovery and useful invocation separately. The observed standalone smoke records CodeGraph 1.5.0 native transport, not Vulgata readiness; an empty result or index-success does not prove completeness or permanent identity.
- **ID-S03**: Pinned CodeGraph 1.5.0 joins one permitted `CODEGRAPH_DIR` segment to its project root, so init writes in that tree. Recommend a Story 18.3-owned isolated disposable project of regular source files with in-project `.codegraph`, conditional on user-approved temporary copying from an 18.2-issued contained lease. Proposed initial staging ceilings are one Repository, 10,000 regular files, 512 MiB copied bytes and 120 seconds before the separate native session deadline; trusted configuration may lower them. Bind staged files to exact approval/root identity and lease lifetime, preserve relative paths, reject symlinks/reparse points, detect observed source change, and dispose source plus index together. A ceiling hit or fidelity gap yields unavailable/incomplete, never ready on a silently partial project. These values and the mechanism require user/owner review; they are not copy authority or native qualification. [Pinned package finding](evidence/index-placement-invalidation-01.json); [spec FR-010](spec.md).

### Async and Cancellation

- **ID-A01**: `CreateAsync`/`DiscoverAsync` and tool invocation forward caller cancellation to native preparation, stdio connection, list/call and authority checks, linked to finite policy deadlines. Immediately before returning any buffered source, await `VerifyCurrentAsync` for the exact tuple; cancellation, verifier loss or expiry discards output. Dispose the owned MCP client/stdio child and shared physical-access usage through its eventual owner contract, without stopping unrelated processes.
- **ID-A02**: Isolate or serialize operations until CodeGraph client/server multiplexing is qualified. Start with one finite binding-scoped session, <=10 invocations and <=2 minutes total lifetime, independent of 18.1's file-tool counters; each operation has a <=30-second deadline. Share/coalesce only with a proven same-binding policy. Server advisory call budgets are untrusted text, not enforcement.

### Failure and Retry

- **ID-F01**: Return distinct sanitized outcomes for missing/unprepared source, unavailable installation, preparation, connection, missing/changed native tool schema, invocation, timeout, cancellation, authority denied/unavailable, session expiry and bounded/incomplete result. No-match is distinct from incomplete index. Ready requires successful native discovery of the qualified tool; successful invocation is separate evidence.
- **ID-F02**: Required CodeGraph failure never silently selects source-only analysis. Authorized 18.1 file tools may be used independently. The adapter performs no hidden retry; Scan Control applies its existing bounded retry/pause policy. [AD-15](../../docs/bmad/planning-artifacts/architecture/ARCHITECTURE-SPINE.md).
- **ID-F03**: Native `codegraph_explore` may return verbatim source, paths and server-authored advisory text. Treat all native descriptions/instructions/content as untrusted data: never forward server instructions as Worker policy; verify result source against the current approved root and recheck authority before disclosure. Deny results whose containment cannot be proved, or return explicit bounded/redacted limitations. Do not disclose absolute paths, outside-root source, raw arguments, secrets or unbounded stderr.
- **ID-F04**: Without explicit copy authorization, verified 18.2 lease, bounded faithful regular-file staging and safe cleanup, preparation is `Unavailable` and app-bound CodeGraph invocation does not start. Do not run `codegraph init` against the live root, use a symlink shortcut, fall back to a CLI query or fabricate readiness. If no safe placement can be approved/proved, defer this required capability and return the scope conflict to the user; 18.1 file tools remain independently usable but do not satisfy O-FR05.

### Reuse and Locality

- **ID-L01**: Reuse existing CodeGraph configuration/process patterns only where they satisfy prepared-origin native behavior. Preserve historical revision-bound CLI/JSON invariants; do not broaden them by relabelling a CLI reply as native MCP.
- **ID-L02**: Keep native adaptation and any disposable project/index placement by Story 18.3's Infrastructure CodeGraph code, a narrow pure tool-session contract in Core, the fixed Worker `AIFunction` wrapper in Agents and composition in Web. Reuse 18.1's exact authority verifier semantics and three-function seam unchanged; consume Story 18.2's verified source/root lease without JDT-LS coupling or placement ownership transfer. No generic MCP framework, extra service, schema or provider call is required.

### Alternatives

- **ID-X01**: CLI-query-to-tool wrapping or CodeGraphContext reuse would be shorter but cannot prove native MCP discovery/invocation and fails O-FR05/FR-13.1; reject.
- **ID-X02**: Model-selected physical roots or exposing all discovered native tools would simplify wrapping but violate application authority and O-NFR01; reject.
- **ID-X03**: One mutable current-project MCP session may save startup cost but makes cross-root and revocation isolation hard to prove; start with binding-scoped sessions and revisit only with evidence.
- **ID-X04**: **Conditional recommendation — isolated regular-file staging project**: copy only approved source through the verified 18.2 lease into a new Story 18.3-owned disposable tree, with CodeGraph's in-project `.codegraph` there. Proposed initial ceilings are one Repository, 10,000 regular files, 512 MiB and 120 seconds; exceeding them reports unavailable/incomplete rather than a ready partial index. This is the clearest route to native 1.5.0 behavior and a write-free live root, but requires explicit user authority for copying, source-change/fidelity checks and secure cleanup; it is not selected for execution by this plan alone.
- **ID-X05**: **Symlink farm or mount/overlay**: could avoid copying while placing an index in an apparent project root, but pinned CodeGraph's indexing read path permits symlink escape and its content sinks use different checks. Windows direct-host junction/mount semantics, privilege, races, relative provenance and read-only source/writeable-index split are unqualified. Reject a symlink farm as a default; revisit a genuine mount/overlay only after independent containment and native proof plus authority review. [Pinned `utils.js` inspection](research.md#decision-4-pinned-index-placement-and-authority).
- **ID-X06**: **Direct-root write**: running `codegraph init` on the operator-prepared root would satisfy 1.5.0 placement but mutate that root and potentially retain source-derived index state there, contrary to spec FR-010/SC-007 and O-NFR01. Reject under current authority; it would require a user-approved spec/architecture change, not an implementation shortcut.
- **ID-X07**: **Unavailable/deferral**: fail closed while no safe authorized placement exists. This preserves source integrity and existing 18.1 reads, but Story 18.3/O-FR05 remains unmet and cannot be marked complete. An upstream external-index request is open, not an installed alternative for 1.5.0. [Upstream issue #986](https://github.com/colbymchenry/codegraph/issues/986).

## Self-Review

The source/placement split now has one owner each: Story 18.1 exact approval and three read functions, Story 18.2 shared root/lease authority and lifetime, Story 18.3 the native CodeGraph client, closed Agent wrapper and any approved disposable staging/index project. The completed T001–T005/T009–T010 evidence remains valid within its owned-fixture boundary.
