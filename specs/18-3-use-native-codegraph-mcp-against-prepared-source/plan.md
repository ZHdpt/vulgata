## Implementation Design

### Responsibilities

- **ID-R01**: The integrated Story 18.1 owns `PreparedSourceApproval`'s exact batch, Repository, subject, `WorkerSourceRead` purpose, approval identity and root-binding identity, live `IPreparedSourceCurrentAuthorityVerifier`, and the public three-function `PreparedSourceFunctions` read seam. Story 18.3 consumes that authority and makes only the spec-bounded internal reader repair; it does not change issuer, public function signatures or historical unbound-source behavior. [Core contract](../../src/dotnet/Vulgata.Core/DomainServices/PreparedSourceContracts.cs); [18.1 contract](../016-contained-source-tools/contracts/prepared-source-tools.md).
- **ID-R02**: Story 18.3 Infrastructure owns declared in-place CodeGraph preparation, one index mutation coordinator, native MCP process/client lifecycle, native result containment, and its generated-state correction within existing prepared-source list/read/search traversal. Agents presents unchanged file tools plus the granted native surface; Web composes. Story 18.2 retains shared prepared-source/root lease and purpose-bound write-capability ownership; Scan Control retains wider scheduling/retry authority.
- **ID-R05**: Story 18.3's reader repair consumes one positively established app-owned CodeGraph state binding from Story 18.2's exact workspace authority. It may exclude that bound state only for the current Repository/root/lifetime; it cannot derive ownership from `.codegraph` spelling, add a second source filter authority, or alter ordinary access to an unbound same-named directory. The precise shared file/type wiring waits for 18.2 owner agreement and independent review. [Spec FR-012/SC-009](spec.md); [owner correction](evidence/source-reader-owner-invalidation-01.json).
- **ID-R04**: The trusted Story 18.3 CodeGraph adapter may create and, at workspace/batch owner disposition, remove only the single root child directory entry `.codegraph`, and may write only its descendants (database, `.gitignore`, observed owned logs/locks) in the dedicated Vulgata-managed workspace. This is not a general workspace-root write grant: prepared source, root `codegraph.json`, Git metadata/hooks and all other root entries stay unchanged. Story 18.2 owns the verified exact-binding, live, Infrastructure-only capability that separately authorizes the single entry action and descendant access; Story 18.3 does not define its interface or a competing lease/filter. CLI/MCP children get descendant rights only. Without the owner checkpoint preparation is `Unavailable`. [Spec FR-010–012](spec.md); [user decision](evidence/user-in-place-design-01.json).
- **ID-R03**: For the observed CodeGraph 1.5.0 surface, application policy grants only native `codegraph_explore` after validating discovery name/schema. The Agent receives a fixed-description wrapper with a closed `query`/bounded `maxFiles` schema; it never receives the raw discovered `AITool`, its `projectPath` parameter or the MCP server's advisory instructions. Unknown/new native tools require separate qualification and grant review. [Raw probe](evidence/native-mcp-standalone-01.raw.json); [Microsoft guidance](https://learn.microsoft.com/en-us/agent-framework/agents/tools/local-mcp-tools).

### State and Lifetime

- **ID-S01**: One finite native session binds the exact `PreparedSourceApproval` tuple and 18.2 lease/workspace identity; no process-global current project crosses roots. Any changed/revoked approval or root-binding identity, verifier unavailability, expired session or lost write/read lease validity latches it closed, discards buffered output and requires a fresh grant. The caller disposes the borrowed Agent wrapper's session after calls settle; concurrent roots cannot inherit one another's connection/index/output.
- **ID-S02**: Index/session/process state stays disposable, separate from 18.1's live source context and canonical Knowledge. Record preparation, native connection, schema-checked discovery and useful invocation separately. The observed standalone smoke records CodeGraph 1.5.0 native transport, not Vulgata readiness; an empty result or index-success does not prove completeness or permanent identity.
- **ID-S03**: Pinned CodeGraph 1.5.0 joins one permitted `CODEGRAPH_DIR` segment to its project root; fix it to `.codegraph` and reject custom placement. In one dedicated managed workspace, the CodeGraph-specific coordinator serializes initialization/index mutation and admits same-binding Workers only after one completed index. It rejects foreign/prior `.codegraph`, then uses the verified 18.2 authorization for the **single `.codegraph` root entry** to create an empty owned directory with child rights confined within it before CLI init; descendant-only authority is insufficient for this step. Pinned `createDirectory` tolerates the empty directory. At most one direct-mode MCP child serves the binding; calls serialize under the 10-call/2-minute session and 30-second call caps. Workers borrow the index and cannot rebuild/delete; release decrements borrowers and may stop an unneeded child, while a later same-binding session may reopen current-owner state. The index persists through dedicated workspace/Scan batch lifetime under exact approval/root/lease/package identity. Only workspace/batch owner disposition, after borrowers/children settle and while the exact entry-removal plus descendant authority remains valid, may clean current-owner tool state. Lost authority or prior-process residue quarantines/marks unavailable for trusted owner reconciliation. No source copy or repository-wide hash/monitor is introduced. [Spec FR-010–012](spec.md); [pinned directory behavior](evidence/codegraph-startup-inspection-01.json).
- **ID-S04**: The internal reader's positive owned-state identity is bound to its exact approval/root and captured continuation state. List pagination and search traversal evaluate eligible source after owned-state exclusion, preserve existing budget/`Limited`/`CompleteEmpty` semantics, and never silently skip or duplicate source. If ownership disappears, changes, or the directory identity changes between pages, return explicit `ChangedInput` or denied and discard the continuation instead of interpreting a new `.codegraph` name match as proof. Direct ranged reads into positively bound state are denied; unbound same-name paths use ordinary Story 18.1 checks. [Read context](../../src/dotnet/Vulgata.Infrastructure/Source/PreparedSourceReadContext.cs); [spec SC-009](spec.md).

### Async and Cancellation

- **ID-A01**: `CreateAsync`/`DiscoverAsync` and invocation forward caller cancellation to finite preparation, stdio connection, list/call and authority checks. The one index coordinator completes or cancels its bounded preparation before readiness; cancellation of one borrower does not delete an index in use by others. Immediately before returning buffered source, await `VerifyCurrentAsync`; loss discards output. Stop only owned helper/MCP children, settle 18.2 lease usage under its owner contract and never stop unrelated processes.
- **ID-A02**: Serialize same-binding native operations until CodeGraph client/server multiplexing is qualified. Use one active finite binding session at a time with <=10 invocations and <=2 minutes total lifetime, independent of 18.1 file-tool counters; each operation has <=30 seconds. New Workers may borrow while exact approval/root/lease and owner-held prepared index remain valid; after a session ends, a later same-binding session may open that index without rebuilding it. No cross-binding sharing or automatic rebuild. Server advisory budgets are untrusted text, not enforcement.

### Failure and Retry

- **ID-F01**: Return distinct sanitized outcomes for missing/unprepared source, unavailable installation, preparation, connection, missing/changed native tool schema, invocation, timeout, cancellation, authority denied/unavailable, session expiry and bounded/incomplete result. No-match is distinct from incomplete index. Ready requires successful native discovery of the qualified tool; successful invocation is separate evidence.
- **ID-F02**: Required CodeGraph failure never silently selects source-only analysis. Authorized 18.1 file tools may be used independently. The adapter performs no hidden retry; Scan Control applies its existing bounded retry/pause policy. [AD-15](../../docs/bmad/planning-artifacts/architecture/ARCHITECTURE-SPINE.md).
- **ID-F03**: Native `codegraph_explore` may return verbatim source, paths and server-authored advisory text. Treat descriptions/instructions/content as untrusted data: never forward server instructions as Worker policy. Validate each canonical relative location and bounded excerpt through Story 18.2's live handle-relative contained read, recheck exact authority before disclosure, and withhold unverified content/location on reparse, replacement race, changed input, read unavailability or mismatch. The fixture client's lexical/path-reopen checks are not production containment evidence. Deny or report explicit bounded/redacted limitations; never disclose absolute/outside-root paths, raw arguments, secrets or unbounded stderr. [Native client](../../src/dotnet/Vulgata.Infrastructure/Analysis/CodeGraph/NativeCodeGraphMcpClient.cs); [definition review](evidence/definition-review-02.raw.json).
- **ID-F04**: Without an exact 18.2 purpose-bound tool-state-write lease and positive owned-state binding usable by Story 18.3's reader correction, clean/current-owner `.codegraph` state, effective child ACL/network confinement and qualified startup footprint, preparation is `Unavailable` before physical execution. Any attempted root config/hook/source write, outbound call or unowned state mutation fails qualification; do not grant broader rights to make it pass. If direct-host confinement or contained native-result read cannot be supplied, return the authority/host conflict instead of CLI/query fallback or fabricated readiness. Independently authorized file tools remain usable under their exact current grant but do not satisfy O-FR05.
