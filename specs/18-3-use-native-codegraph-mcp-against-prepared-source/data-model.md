# Transient Data Model: Native CodeGraph Tool Boundary

No persistent entity or migration is introduced. Story 18.1's exact authority types are integrated; Story 18.2's shared source/root lease is pending, while Story 18.3 owns any separately approved CodeGraph staging/index location. These are conceptual request-scoped values, not a second source grant or authorization to copy. [Plan ID-I01/I05/S03](plan.md); [spec FR-010](spec.md); [18.1 Core contract](../../src/dotnet/Vulgata.Core/DomainServices/PreparedSourceContracts.cs).

| Record | Fields and validation | Lifetime / relationship |
|---|---|---|
| Prepared source approval (18.1) | Existing `PreparedSourceApproval`: batch, Repository, subject, `WorkerSourceRead` purpose, approval identity, root-binding identity and label; exact current verifier response. No model-visible physical path. | Trusted input; changed/revoked/unavailable current approval closes native session and withholds buffered output. |
| Shared source/root lease (18.2) | Owner-issued contained source access, exact root identity and lifetime; callable type awaits its identifiable verified checkpoint. | Supplies only source/root authority to 18.3; no inferred copy or writable-index grant. |
| Conditional CodeGraph staging project (18.3) | Owned disposable project tree of approved regular source files; exact approval/root binding, relative-path mapping and proposed ceilings of one Repository, 10,000 files, 512 MiB and 120 seconds. Requires separate user authorization for temporary copying and verified 18.2 lease reads. | Created only after both authorities; reject symlink/reparse entries, observed change and cap overflow; never mark a partial staged project ready. Remove source and index on cancellation, expiry or completion. No public Source Snapshot identity or retention. |
| CodeGraph tool state (18.3) | In-project `.codegraph` index under the conditional staging root; `CODEGRAPH_DIR` may rename its one segment but cannot externalize it in pinned 1.5.0. | Disposable with the staged project; never written into operator-prepared live source. |
| Native session (18.3) | Exact approval tuple, declared CodeGraph installation, finite policy deadline/budget, connection state, qualified `codegraph_explore` discovery and owned MCP client/process. | One binding-scoped `IAsyncDisposable` session; caller owns disposal, Agent function borrows it; no cross-root reuse. |
| Native tool grant (18.3) | Fixed `codegraph_explore`; closed `query` and capped `maxFiles`, with native `projectPath` injected privately. | Revalidated before registration/invocation; raw MCP `AITool` and server instructions never become Worker grants. |
| Readiness observation | Distinct preparation, connection, discovery/schema and invocation statuses with sanitized failure/limitation; no source/path. | Per session/attempt; standalone native proof does not mark Vulgata Agent ready. |
| Invocation outcome | Bound Repository ID, status, bounded source and verified relative location or typed failure, explicit incompleteness/limit. | Released only after exact current authority and containment checks; no-match is not proof of absence. |

## State transitions

`PlacementPending -> AuthorizedLeaseAndCopy -> Staging -> Preparing -> Prepared -> Connecting -> DiscoveredAndQualified -> Invoking -> Completed -> Disposed` is the proposed successful physical route. Copy authority, verified 18.2 lease and safe staged source are independent prerequisites. If any is absent, return `Unavailable` before staging/CodeGraph init and do not target the live root. Staging rejects symlink/reparse entries and observed source change; cleanup settles staged regular files and index together. Later steps retain explicit unavailable/failure/timeout/cancellation. Revoked/changed approval, unavailable verifier, expired session or lost lease latches terminal closed and discards buffered content/location. The completed owned-fixture native/controlled evidence remains distinct from Vulgata physical integration.
