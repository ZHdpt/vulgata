# Transient Data Model: Native CodeGraph Tool Boundary

No persistent entity or migration is introduced. Story 18.1's exact authority types are integrated; the Story 18.2 shared trusted physical-workspace contract is an unresolved construction dependency. These are Story 18.3 request-scoped values, not a second source grant. [Plan ID-I01/I05/S01](plan.md); [18.1 Core contract](../../src/dotnet/Vulgata.Core/DomainServices/PreparedSourceContracts.cs).

| Record | Fields and validation | Lifetime / relationship |
|---|---|---|
| Prepared source approval (18.1) | Existing `PreparedSourceApproval`: batch, Repository, subject, `WorkerSourceRead` purpose, approval identity, root-binding identity and label; exact current verifier response. No model-visible physical path. | Trusted input; changed/revoked/unavailable current approval closes native session and withholds buffered output. |
| Shared trusted physical workspace (18.2) | Owner-issued contained physical access bound to the approved root; exact type, construction and expiry await its identifiable verified checkpoint. | Consumed by 18.3's native process only after verification; no parallel lease authority. |
| CodeGraph tool state (18.3 in 18.2-owned workspace) | Writable `.codegraph` index tied to the approved source view; exact safe location/mapping awaits the shared workspace checkpoint. | Disposable within the granted tool-workspace lifetime; never presumed writable in operator-prepared live source or created by an unapproved source copy. |
| Native session (18.3) | Exact approval tuple, declared CodeGraph installation, finite policy deadline/budget, connection state, qualified `codegraph_explore` discovery and owned MCP client/process. | One binding-scoped `IAsyncDisposable` session; caller owns disposal, Agent function borrows it; no cross-root reuse. |
| Native tool grant (18.3) | Fixed `codegraph_explore`; closed `query` and capped `maxFiles`, with native `projectPath` injected privately. | Revalidated before registration/invocation; raw MCP `AITool` and server instructions never become Worker grants. |
| Readiness observation | Distinct preparation, connection, discovery/schema and invocation statuses with sanitized failure/limitation; no source/path. | Per session/attempt; standalone native proof does not mark Vulgata Agent ready. |
| Invocation outcome | Bound Repository ID, status, bounded source and verified relative location or typed failure, explicit incompleteness/limit. | Released only after exact current authority and containment checks; no-match is not proof of absence. |

## State transitions

`Unprepared -> Preparing -> Prepared -> Connecting -> DiscoveredAndQualified -> Invoking -> Completed` is the successful route only after safe writable tool-state placement is verified. If the shared workspace cannot supply it, preparation is unavailable and cannot target the live root. Each later step can terminate with explicit unavailable/failure/timeout/cancellation; discovery may reject missing or changed `codegraph_explore` schema, and result may be limited. Revoked/changed approval, unavailable verifier, expired session or invalid shared workspace latches terminal closed, discards buffered content/location and requires a new grant. Preparation/connection/discovery readiness and standalone invocation evidence are distinct from Vulgata Worker invocation.
