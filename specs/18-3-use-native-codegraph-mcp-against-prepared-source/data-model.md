# Transient Data Model: Native CodeGraph Tool Boundary

No persistent entity or migration is introduced. Story 18.1's exact authority types/public three-function seam are integrated. Story 18.2 owns shared root/lease, pending write adjustment, contained read and positive owned-state binding; Story 18.3 owns CodeGraph index/startup/session policy and the bounded correction to existing prepared-source reader internals. These conceptual values do not define a second source grant or shared interface. [Plan ID-I01/I05–I07/S03–S04](plan.md); [spec FR-010–012](spec.md); [18.1 Core contract](../../src/dotnet/Vulgata.Core/DomainServices/PreparedSourceContracts.cs).

## State transitions

`Unqualified -> BoundWriteLeaseAndChildConfinement -> PreExistingStateChecked -> OneOwnerPreparing -> Prepared -> Connecting -> DiscoveredAndQualified -> Invoking -> ContainedResultVerified -> Completed -> SessionReleased -> WorkspaceOwnerDisposition` is the successful physical route. Story 18.3's reader correction separately consumes the positive owned-state binding for each list/read/search operation and continuation; if binding/directory identity changes, return `ChangedInput` or denial rather than silently skip source. Missing owner checkpoint, unsafe pre-existing state, unqualified child confinement or unavailable contained read returns `Unavailable`/explicit limitation before app-bound disclosure. Same-binding Workers borrow one prepared index; session release never rebuilds/deletes it. Only workspace/batch owner disposition cleans owned state while write authority persists; otherwise quarantine. Revoked/changed approval, unavailable verifier or expired lease closes native session and discards buffered content/location. Controlled owned-fixture startup may precede owner checkpoint, but cannot establish app-bound readiness.
